## 1. Introduction

This lab practical was carried out to gain hands-on experience in Linux package management, a core skill for system administrators and DevOps professionals. Package management is the process of installing, upgrading, configuring, and removing software packages on a Linux system using specialized tools such as apt for Debian/Ubuntu systems or yum/dnf for Red Hat-based systems. Efficient package management ensures system stability, security, and access to the latest features.

The objectives of this lab were to become proficient in performing common package management tasks, including updating repositories, installing new packages, removing software, searching for available packages, listing installed packages, and upgrading existing packages. Conducting these operations in a virtualized environment allowed for safe experimentation without risking a production system, simulating real-world scenarios where Linux servers are managed remotely.

The lab was performed using a virtual Linux environment provisioned with Vagrant running Ubuntu 18.04 LTS. This setup replicated a standard server configuration and enabled me to troubleshoot real-world challenges such as repository access issues, network connectivity problems, and dependency conflicts. Throughout the lab, I focused on understanding how package managers interact with repositories, resolve dependencies, and maintain system integrity.

By completing this lab, I aimed to develop practical competence in Linux software management and enhance problem-solving skills necessary for system administration. This exercise provided insight into the automation of software maintenance and reinforced best practices for keeping Linux systems secure, up-to-date, and optimized for performance.
